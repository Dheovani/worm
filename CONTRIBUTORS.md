# Contributors

Worm recognizes people whose accepted code, documentation, design, testing, review, or security work is present in the project. Names are derived from the public Git history and consolidated when one person has used more than one commit identity.

## Current contributors

- Dheovani Xavier da Cruz (`@Dheovani`) — original author and maintainer.

## Recognition policy

Add a contributor after their first accepted contribution reaches the default branch. Use the name and handle they provide publicly, preserve `Co-authored-by` metadata when applicable, and describe substantial user-visible work in the changelog. Automated tools and bots remain attributable through commit and pull-request metadata rather than this human-contributor list.

Important architectural decisions are recorded in [docs/technical-decisions.md](docs/technical-decisions.md). A contribution that introduces, replaces, or materially changes an architectural boundary must update that record in the same pull request so the reasoning remains public with the implementation.
